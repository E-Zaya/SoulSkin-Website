## 4. 進め方（提案・1案）

**方針: 9/5 の未コミット作業（UB RAW PRECISION）を土台にし、design.md の数値に合わせて「文字・ラベル・架空データ」を直す。** 写真・黒×骨色・Hero 映像・固定ナビは資産として残す（設計書の判断と同じ）。

1. **Phase 0 衛生（1コミット）**: 作業中の変更を WIP コミット → `.codex-chrome-home-*` を ignore + 削除（履歴対応は中身を見て判断）→ verify PNG / lib.zip 削除 → 孤児 9コンポーネント + 未使用 40クラス削除 → eslint ignore 整理 → middleware を proxy へ
2. **Phase 1 トークン統一**: `--ss-*` と `--color-*` を `@theme` の1セットへ。文字サイズを 7段（13 / 14 / 16 / 18 / 24 / 36 / 56 + display）に固定し **最小 12px、ラベル 13px**。フォントを 2ファミリーへ（Bebas Neue + 本文1つ。Playfair か Space Mono を落とす）。主色は青1つ、赤は LIVE/SOLD OUT だけ
3. **Phase 2 ページ**: 詳細2ページを新システムへ。架空メタを実データに置換するか削除。/pieces のフィルターは機能させるか削除。/drops レール・/lookbook モバイルの再配置
4. **Phase 3 仕上げ**: focus-visible 全部品、スキップリンク、Hero 停止ボタン、ScrollReveal を見せ場1箇所に、タップ 44px、theme-color、画像を WebP 化・OG を 1200×630 に
5. **文書**: README を実態に合わせて書き直す

完了判定は design.md 9章（計測 → 検索 → 1440/375 目視 → 判定）を Phase ごとに1回。
